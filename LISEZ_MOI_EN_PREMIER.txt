🎯 LISEZ-MOI EN PREMIER!
========================

Bienvenue dans MyFitTracker v1.0.0! 💪

Ceci est l'application COMPLÈTE et prête à utiliser.

📱 LANCEMENT INSTANTANÉ
========================

**Option 1: Le Plus Simple**
1. Double-cliquez: index.html
2. L'app s'ouvre dans Chrome ✅
3. C'est tout!

**Option 2: Avec Serveur Local**
```
Ouvrez PowerShell dans ce dossier
Tapez: python -m http.server 8000
Allez à: http://localhost:8000
```

**Option 3: Sur Votre Téléphone**
1. Lancez le serveur local (Option 2)
2. Chrome sur téléphone: http://ADRESSE_IP:8000
3. Menu (⋯) → Installer l'app
4. Voilà! 🚀

🎮 PREMIÈRE SESSION (3 MIN)
============================

1. Accueil → Voir vos stats
2. 📋 Changer Programme → Upper Body
3. ▶ Commencer Session
4. Cliquez exercice (ex: Bench Press)
5. Regardez l'animation SVG
6. Remplissez: Reps, Poids, RPE (1-10)
7. + Ajouter → Répétez 3x
8. Exercice Suivant →
9. ✓ Terminer Session

✅ Vos données sont sauvegardées!

🌐 SUR GITHUB PAGES (Partout!)
===============================

Pour avoir l'app accessible partout (pas besoin du PC):

1. Poussez sur GitHub:
```
git init
git add .
git commit -m "Initial: MyFitTracker v1.0.0"
git remote add origin https://github.com/VOTRE_USERNAME/MyFitTracker_YDS.git
git branch -M main
git push -u origin main
```

2. GitHub.com → Settings → Pages → Source: main

3. L'app sera à:
https://VOTRE_USERNAME.github.io/MyFitTracker_YDS

4. Ouvrez sur votre téléphone → Installer comme app!

💡 CONSEILS RAPIDES
====================

⚙️ Modifier Exercices
- Ouvrez: js/exercises.js
- Trouvez EXERCISES_DATABASE
- Éditez et rafraîchissez (Ctrl+Shift+R)

🎨 Changer Couleurs
- Ouvrez: css/styles.css
- Éditez :root variables
- Rafraîchissez

📤 Exporter Vos Données
- ⚙️ Paramètres → 📥 Exporter Données
- Fichier JSON téléchargé
- Sauvegarde de secours!

🗑️ Effacer Toutes Données
- ⚙️ Paramètres → 🗑️ Tout Effacer
- Avec double confirmation (par sécurité)
